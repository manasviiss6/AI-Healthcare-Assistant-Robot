# AI Healthcare Assistant Robot

## Overview
An AI-enabled healthcare assistant robot designed for real-time patient monitoring and interaction using embedded systems and Raspberry Pi.

## Features
- Real-time health monitoring
- Voice-based interaction
- Face detection and emotion recognition
- Flask-based monitoring dashboard
- Sensor integration

## Components Used
- Raspberry Pi
- ECG Sensor
- Temperature Sensor
- Pulse Sensor
- Ultrasonic Sensor

## Technologies Used
- Python
- Flask
- OpenCV
- TensorFlow Lite
- Embedded Systems

## Applications
- Patient monitoring
- Smart healthcare assistance
- IoT healthcare systems
